# cpp-data-structure-museum

## Overview
This is a C++ programming assignment focused on implementing classes and data structures. It models a museum using exhibits, a vault, and a corridor.

## Concepts Demonstrated
- **Object-oriented programming:** Classes, private data members, and validation methods
- **C++ templates:** Reusable classes that work with different data types
- **Dynamic arrays:** Managing dynamically allocated memory
- **Linked lists:** Organizing and connecting nodes
- **Testing and experimentation:** Running program checks and recording results

## Project Files

| File | Description |
|---|---|
| `main.cpp` | Program entry point and test driver |
| `exhibit.h` | Exhibit class implementation |
| `vault.h` | Template class using a dynamic array |
| `corridor.h` | Template class using a linked list |
| `counters.h` | Counter declarations |
| `counters.cpp` | Counter implementations |
| `RESULTS.txt` | Recorded experiment results |
